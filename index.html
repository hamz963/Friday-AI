🎓 Educational Purpose & Sandboxing

Friday AI is designed as a secure, educational workspace to explore autonomous agent actions. Letting LLMs execute shell commands directly on a host operating system presents significant security risks. Friday AI implements a multi-tiered defense:

  • Whisper Flow Refiner: Normalizes stutters and maps speech to strict, pre-approved action parameters.
  • Terminal Sandbox: Filters out destructive patterns (e.g., recursive deletes, root access attempts).
  • Safe Diagnostics Loop: Restricts compilations and checks to sandboxed workspace folders.
